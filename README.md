
# Linux-retr-Emula-o-de-PS1-e-gamecube-em-PCs-Antigos
Tutorial passo a passo

📌 Objetivo

- Demonstrar que um computador antigo pode ser reutilizado para entretenimento e estudos, utilizando Linux e softwares de emulação.

- Durante o projeto serão abordados:

- Instalação do Linux;

- Configuração do sistema;

- Instalação dos emuladores;

- Configuração de controles;

- Otimização do desempenho;

- Testes de jogos;

- Análise das limitações do hardware

🐧 1. Instalação do Linux
Primeiramente, foi instalada a distribuição [NOME DA DISTRIBUIÇÃO].

Passos
Baixar a ISO do Linux.

Criar um pendrive bootável.

Inicializar o computador pelo pendrive.

Instalar o sistema operacional.

Reiniciar o computador.

Remover o pendrive.

Após a instalação, o sistema foi atualizado:

sudo apt update
sudo apt upgrade

Os comandos podem variar dependendo da distribuição Linux utilizada.

🎮 4. Emulação de GameCube
Para GameCube foi utilizado o Dolphin Emulator.

O Dolphin possui requisitos maiores que os emuladores de PS1, portanto seu desempenho depende bastante do processador e da placa de vídeo.

⚙️5 . Otimização para PC antigo
Como o projeto utiliza hardware antigo, algumas otimizações podem melhorar o desempenho.

Recomendações
Utilizar um ambiente gráfico leve;

Fechar programas desnecessários;

Reduzir a resolução dos jogos;

Desativar filtros gráficos;

Utilizar resolução interna 1x no Dolphin;

Manter os drivers gráficos atualizados;

Verificar a temperatura do computador.
